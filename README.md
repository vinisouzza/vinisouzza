## 🚀 Projetos em Destaque

### [SEC Filings Intelligence Pipeline](https://github.com/vinisouzza/sec-filings-intelligence-pipeline)
Pipeline de dados em camadas (Raw → Bronze → Silver → Gold) orquestrado com
Apache Airflow, processando dados públicos da SEC EDGAR API.
- Modelagem analítica com **dbt** e **DuckDB** (staging e marts), com scorecard
  de qualidade e observabilidade de pipeline
- Testes automatizados em duas camadas (**Pytest** + **dbt tests**)
  e CI/CD com **GitHub Actions**
- Dashboard interativo em **Streamlit/Plotly** com KPIs e métricas da camada Gold

**Stack:** Python · Airflow · dbt · DuckDB · Docker · Pytest · Streamlit · GitHub Actions

---

### [YouTube Data ELT Pipeline](https://github.com/vinisouzza/YT_ELT)
Pipeline ELT que coleta estatísticas de vídeos via API do YouTube, com
armazenamento em **PostgreSQL** (Staging/Core), orquestração via **Airflow**,
qualidade de dados com **Soda Core** e testes com **Pytest**.

**Stack:** Python · Airflow · PostgreSQL · Soda Core · Pytest · Docker · GitHub Actions

---

### [Crypto ETL Pipeline](https://github.com/vinisouzza/crypto-etl-airflow)
Pipeline ETL para coleta horária de preços via API CoinGecko, com armazenamento
em **PostgreSQL** e visualizações no **Metabase**.

**Stack:** Python · Airflow · PostgreSQL · Metabase · Docker
